# Changelog

All notable changes to the **Quick Hide** extension are documented here.

## 1.0.1

- Republished as a new version to refresh the Marketplace listing; includes the extension icon.

## 1.0.0

- Initial public release.
- Manage your user `files.exclude` patterns from a toggle list in the Explorer.
- Add, edit, and remove glob patterns without opening `settings.json`.
- Organize patterns into named groups and toggle a whole group at once.
